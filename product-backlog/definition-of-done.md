# Definition of Done

The increment is done when:

- [ ] All acceptance criteria in `Confirmation.md` are met
- [ ] Automated tests pass (unit tests, plus integration tests for any API or middleware involved)
- [ ] No known defects remain
- [ ] The feature is demoable to stakeholders
- [ ] Financial calculations (budget, interest, TAEG, savings) are validated against a trusted reference
- [ ] User-facing content is in clear pt-PT, neutral, jargon-free and based on real data with a cited source
- [ ] The feature works on mobile and desktop, and personal financial data is never exposed or stored insecurely
